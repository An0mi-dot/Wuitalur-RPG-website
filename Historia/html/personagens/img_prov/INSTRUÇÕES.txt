INSTRUÇÕES PARA IMAGENS DA PROVIDÊNCIA
=====================================

Para adicionar imagens que piscarão no fundo da página da Providência:

1. Coloque suas imagens nesta pasta (img_prov)

2. Nomeie os arquivos como:
   - img1.jpg, img2.png, img3.gif, etc.
   - image1.jpg, image2.png, etc.
   - bg1.jpg, bg2.png, etc.
   - pic1.jpg, pic2.png, etc.
   - photo1.jpg, photo2.png, etc.

3. Formatos suportados: JPG, JPEG, PNG, GIF, WEBP

4. Recomendações:
   - Use até 5 imagens para melhor performance
   - Imagens com resolução entre 200x200 e 500x500 pixels
   - Imagens escuras ou com temas sombrios funcionam melhor
   - O sistema aplicará automaticamente filtros de cor e efeitos

5. Se não colocar imagens, o sistema criará efeitos visuais alternativos automaticamente.

EXEMPLO DE NOMES VÁLIDOS:
- img1.jpg
- img2.png  
- img3.gif
- img4.webp
- img5.jpeg

O sistema tentará carregar automaticamente qualquer imagem com esses padrões de nome!
